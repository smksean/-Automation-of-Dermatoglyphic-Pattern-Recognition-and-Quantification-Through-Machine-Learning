# Quantification Reference Results

These aggregate tables and figures are generated by
`notebooks/12_quantification_reference_analysis.ipynb` through
`scripts/build_quantification_reference.py`.

The canonical cohort uses SD302b baseline device V, 1000-ppi rolled
impressions. Subject-level rows remain under the ignored `data/` tree. Public
outputs contain no subject identifiers, image paths, coordinates, or biometric
images.

Pattern intensity and examiner-marked minutiae totals are calculated. Total
finger ridge count was reviewed as a candidate endpoint, but it is not reported
as a primary quantitative outcome because the restored SD302g annotations do not
include validated expert field `9.322` ridge-count values.
