# Automation of Dermatoglyphic Pattern Recognition and Quantification Through Machine Learning

This project prepares NIST SD302 fingerprint records for dermatoglyphic pattern classification.

The notebook workflow focuses on:

- extracting pattern labels from SD302g EBTS/IRR records
- linking extracted labels to matching fingerprint images
- creating review samples for human verification
- preparing a clean path toward broad and subtype fingerprint classification

## Data Notice

The NIST SD302 dataset is not included in this repository. The raw biometric data, generated review images, processed CSV files, and other derived data artifacts are intentionally excluded from GitHub because the dataset has redistribution restrictions.

Run the notebooks locally after placing the SD302 files in the expected workspace folders.
